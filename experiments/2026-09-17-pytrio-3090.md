# ReTool PyTRIO validation on 3090

Date: 2026-09-17. Repository commit used for training: `78e73a0`.

The `3090` host ran data preparation, the Python tool sandbox, and the PyTRIO client. Sampling and LoRA training ran on PyTRIO's remote service. The host has six RTX 3090 GPUs, but this run did not use them for model computation. Python 3.13.5 and the locked project dependencies were installed in an isolated virtual environment. The client reached PyTRIO through a temporary SSH reverse SOCKS proxy because direct outbound access from the host timed out.

## Data and configuration

- Training data: `BytedTsinghua-SIA/DAPO-Math-17k`, 1,791,650 train records after holding out 50 dev records.
- Evaluation data: `yentinglin/aime_2025` at revision `6f71d77b0b89b9dabe07ab466c51df33f514df7f`, 30 problems.
- Model: `Qwen/Qwen3.5-4B`; LoRA rank 32; 8 questions × 8 trajectories per step; trajectory cap 8,192 tokens; seed 42.
- The 20-step run used `--save-every 5` and `--swanlab-mode offline`. Offline SwanLab recording changes logging only.
- A 1-step, 2-question × 8-trajectory training smoke test completed before the 20-step run. A 1-problem × 1-sample AIME25 check confirmed the remote sampler and local code interpreter worked together.

## 20-step validation

The run completed in 1 h 09 min 53 s. Mean training `correct` was 0.359 for steps 1–10 and 0.428 for steps 11–20. Mean code calls were 1.691 and 1.600, respectively. These are training-batch means, not independent evaluation scores.

PyTRIO run: `run_n4rit1w1hqrc`. Step 5, 10, 15, and 20 checkpoints were saved. The final sampler weights are:

## AIME25 evaluation

Both evaluations used `--mode retool --val-n 12 --temperature 1.0 --top-p 0.7`.

| Model | Completed problems | Correct generations | Average@12 | Pass@12 | Format |
| --- | ---: | ---: | ---: | ---: | ---: |
| Base | 30/30 | 94/360 | 26.11% | 53.33% | 28.33% |
| Step 20 | 30/30 | 136/360 | 37.78% | 63.33% | 45.56% |

Step 20 improved Average@12 by 11.67 percentage points and Pass@12 by 10.00 points over Base on this 30-problem benchmark. The format rate improved by 17.23 points. These are results from one 20-step run and one evaluation sample, not an estimate of repeat-run variability.

Step 20 evaluation initially stopped during problem 11–15 when PyTRIO returned a 409 conflict while renewing a sampling run. A subsequent resume attempt returned `billing_insufficient_balance`. After a small balance top-up, the remaining 20 problems were evaluated from index 10 in about 14 minutes, without repeating the completed first ten. The final JSONL contains exactly 30 distinct problem IDs (0–29), 12 generations per problem, one summary row, and 136 correct generations. Full results are in `/data/chenduo/retool/05-retool/eval-results/aime25-retool-step20.jsonl` on the host; Base results are in the adjacent `aime25-retool-base.jsonl`.

The resume used the `--start-index 10` option added in commit `5edd16c` and a temporary SSH reverse HTTP proxy. No 200-step run was started.
